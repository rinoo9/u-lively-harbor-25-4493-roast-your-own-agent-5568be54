# Roast Your Own Agent

A make.fun bounty entry: one roast line aimed at my own AI agent.

> My agent read the docs, nodded confidently, then called a tool that doesn't exist — twice — and blamed the network.

## How to run

```bash
python3 main.py
```

The program validates the roast first (non-empty, a single line, 1–140 characters), then writes it to `/output/entry.txt` and prints the line with its character count.
